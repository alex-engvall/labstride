Labstride is a self-hosted development workflow coordinator being built around your existing tools. Its intended workflow connects a request in GitHub to an isolated workspace, repository-owned workflows and observable results.

:::caution[In development]
There is no installable release yet. Some components have scoped implementation and test evidence, but the complete public installation and end-to-end product are not ready. This documentation site does not change that status.
:::

## Documentation and specifications

This site is the public reading guide. Detailed specifications, architecture decisions, requirement tracking and verification evidence remain in the repository's [`docs/` directory](https://github.com/engshort/labstride/tree/main/docs).

When reading an example or a proposed contract, distinguish intended behavior from implemented behavior and from behavior verified in a particular environment. The repository records those boundaries explicitly.
