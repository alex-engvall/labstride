These files remain the source for current progress. This page deliberately does not duplicate a changing feature checklist.

## Intended first public release

The planned foundation includes a coordinator and CLI, GitHub integration, SSH workspaces, repository-owned delivery workflows and an explicit cleanup action. Agent integration is optional; the public path must work without a private agent extension.

Linux is the first intended verified runtime and SSH target. Other platforms require their own execution evidence before support can be claimed.

Installation and upgrade instructions will be added when the corresponding public artifacts and clean-install checks exist. See the [release gates](https://github.com/engshort/labstride/blob/main/docs/13-pilot-and-release.md) rather than guessing an installation command.
