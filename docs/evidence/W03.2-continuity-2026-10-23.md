## Implemented integration

The coordinator checks its original pinned artifact before calling the frozen session provider. Artifact tampering fails before another provider call. Legacy unconfigured sessions retain their original behavior.

The [continuity tool](../34-exact-revision-workspaces.md#integrated-continuity-qualification) composes actual GitHub polling/admission, workspace execution/recovery and installed session commands. Versioned protected descriptors bind the original fixture, source, pins and coding identity. GitHub authentication remains local to the stdio bridge. Owned fixture effects are journaled before submission; an uncertain response never authorizes repeating them.

Its phases prepare two owned issue generations, reject a controlled GitHub write, lose an actual projection acknowledgement, lose a real SSH creation reply, kill the test coordinator, recover the original workspace operations, enroll an existing coding-account client session and reject a stale continuation after the operator's human turn. The root supervisor checks process UID, executable and ancestry before signals. The explicit final fixture phase deletes only its uniquely identified Project; all workspaces and execution evidence are retained.

**These live phases have not been executed.** Their implementation is not acceptance evidence.
