# Governance

Alexander Engvall (alex-engvall) is the initial maintainer and owns the original work he contributes. External contributors retain their own copyrights. The Apache-2.0 license grants reuse rights; it does not make every user a joint copyright owner.

Product discussion happens in issues. Substantial changes use a short proposal and an architecture decision record explaining alternatives, effects and migration. The maintainer resolves scope and release decisions while the project is small. Additional maintainers can be appointed transparently as participation grows.

Public and private extensions use identical technical contracts. Private functionality must not be required to install or use the public core. No contribution is promised inclusion; rejection should explain technical or scope reasons.

Use respectful, specific feedback. Harassment and publication of other people's private information are unacceptable. A private reporting route and backup maintainer procedure must be established before the first public release; no nonexistent email address is advertised here.

Previously released license grants remain governed by their license. A future license/governance change requires an explicit decision and consideration of all contributors' rights.
